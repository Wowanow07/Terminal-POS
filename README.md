2. Використання програми
    2.1. Для ввімкнення термінала потрібно натиснути на свіч, який знаходить по центру, та зачекайте його завантаження
	     (Примітка: Для роботи програми потрібне підключення до інтернету)
    2.2. Оплата: Для того щоб провести операцію потрібно: натиснути на зелену кнопку, потім кнопками F2-F3 вибрати потрібну операцію, після   	 чого натиснути на зелену кнопку.
	     З'явиться поле введення суми, потрібно ввести суму за допомогою клавішами цифр на панелі і натиснути далі. Після потрібно виконати 	 дію "прикласти карту".
	     Після прикладання карти ввести PIN-код (Примітка: Програмі не реалізовано перевірка справжнього PIN-коду, тобто можна ввести любий 	 PIN-код, головне щоб його довжина дорівнювала 4-цифр), далі натиснути зелену            кнопку та зачекати обробку транзакції . Якщо операція не вдала повторюємо операцію.
    2.3. Повернення: Для того щоб повернути кошти потрібно: натиснути на зелену кнопку, потім кнопками F2-F3 вибрати потрібну операцію, після 	 чого натиснути на зелену кнопку.
	     З'явиться поле введення номера чека(номер чека знаходиться у нижньому правому куті) потрібно номер чеку за допомогою клавішами цифр 	 на панелі і натиснути далі
	     (Примітка: Якщо операція оплата була невдалою, то номер чека не зберігається), після підтвердження чека потрібно ввести суму на яку 	 було проведено операцію і потім підтвердити введені дані.
3. Допоміжні Функції
    3.1. Кнопка редагування(Жовта): Очищає поля введення даних
    3.2. Кнопка скасування операції(Красна): Скасовує операцію та повертає програму на головний екран
